## Source Data and Attribution

The datasets in this repository are compiled from multiple sources. Their original licensing and attribution requirements remain applicable where relevant.

### ONEI / CoDPA

The Código de la División Político-Administrativa (CoDPA) is used as the source for Cuba's administrative inventory, official names, codes, levels, and administrative relationships.

Source: [Oficina Nacional de Estadística e Información (ONEI), Cuba](https://onei.gob.cu/).

### NGA Geographic Names Server

Geographic names and locations from the [National Geospatial-Intelligence Agency Geographic Names Server (GNS)](https://geonames.nga.mil/geonames/GNSHome/) are used in the administrative geographic names product.

NGA states that GNS data have no licensing requirements or restrictions; citation of the source is recommended.

### GeoNames

[GeoNames](https://www.geonames.org/) data are available under the [Creative Commons Attribution 4.0 International License (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/) and require attribution to GeoNames.

### Overture Maps

[Overture Maps Divisions](https://docs.overturemaps.org/attribution/) data used by this project are distributed under the [Open Data Commons Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

The administrative geometry product therefore retains the ODbL 1.0 license.

Overture's attribution requirements for the Divisions theme include attribution to [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).

[Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) data used by this project are in the public domain.
