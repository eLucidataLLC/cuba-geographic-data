# Cuba Administrative Geographic Names

[GeoParquet](cuba_administrative_geographic_names.parquet) · [GeoJSON](cuba_administrative_geographic_names.geojson) · [GeoPackage](cuba_administrative_geographic_names.gpkg)

## Use

Use this table to obtain official administrative labels and source point locations. Join geometry.gazetteer_id to this product’s id. Preserve CoDPA codes as strings.

The GeoPackage table/layer is `cuba_administrative_geographic_names`. Alternative formats represent the same product.
