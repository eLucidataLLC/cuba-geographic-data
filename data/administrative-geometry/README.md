# Cuba Administrative Geometry

[GeoParquet](cuba_administrative_geometry.parquet) · [GeoJSON](cuba_administrative_geometry.geojson) · [GeoPackage](cuba_administrative_geometry.gpkg)

## Use

Select level before aggregating areas: provinces and municipalities overlap. Join gazetteer_id to id in the administrative names product. Isla de la Juventud is one special_municipality record, not a duplicated province record.

The GeoPackage table/layer is `cuba_administrative_geometry`. Alternative formats represent the same product.

## Documentation

- [Metadata](metadata.xml): description, coverage, lineage, limitations, license and source attribution. This is the authoritative product metadata.
- [Field definitions](fields.json): logical types, null semantics, units, controlled values and relationship targets.
- [Checksums](checksums.json): filenames, byte sizes and SHA-256 hashes for download verification.

Cross-product references identify related records; they do not require copying another product into this folder.
